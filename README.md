# Ліхтарник

Браузерна 3D-гра про програмування: рух, повороти, цикли, стрибки та запалювання ліхтарів. П’ять початкових рівнів, темна тема та оригінальна процедурна музика (вмикається кнопкою).

## Запуск

Потрібен Node.js. Без npm та встановлення пакетів:

```
node server.cjs
```

Гра: http://localhost:5173/
Прихований редактор: http://localhost:5173/admin/

Сервер слухає лише 127.0.0.1. Посилання на адмінку в грі немає. Це локальний інструмент без облікових записів, не публічна захищена адмін-панель.

## Редактор

Поля 2–10 клітинок по кожній осі. Висоти 0–5, порожні місця, дерева, ліхтарі, старт і напрямок. Вибір доступних команд та ліміт блоків (0 = без ліміту). Карта редагується зверху, кнопка 3D показує результат. Цифри на клітинках — їх висоти. Є скасування останніх 40 змін карти.

«Зберегти» записує levels/<id>.json та оновлює levels/index.json. Для редагування наявного файла спочатку відкрий його зі списку. «Зберегти копію» створює новий ID. Чернетка зберігається в localStorage цього браузера. «Тестувати» відкриває гру з чернеткою через sessionStorage, повернення відновлює редактор. Кнопка JSON завантажує файл вручну.

Для кожного рівня можна додати до п’яти підказок: текст і місце, яке слід підсвітити. Нові рівні не мають підказок. Якщо підказки додані, гра показує їх під час першого відкриття рівня у вкладці браузера; кнопка «? Підказка» відкриває їх знову. Підказки зберігаються лише у JSON відповідного рівня (`hints`).

## Правила

- Вперед — сусідня клітинка тієї ж висоти.
- Вліво / вправо — поворот на місці.
- Стрибок — сусідня клітинка попереду, перепад не більш як 1 (вгору чи вниз).
- Дерево та порожня клітинка непрохідні.
- Запалити ліхтар — на поточній клітинці. Повторне запалювання не змінює стан.
- Іскристий ліхтар треба полагодити ремкомплектом: спроба ввімкнути або вимкнути його вдарить персонажа струмом і зупинить програму. Рух та інші команди не б’ють струмом.
- Цикл — 2–10 повторів; цикли можна вкладати в інші блоки. Цикл і його внутрішні блоки враховуються в ліміті один раз.
- Для додавання команд у цикл натисни «Додавати команди в цикл» або перетягни їх усередину. Переставляй блоки, кидаючи на заголовок потрібного блока (вставка перед ним); кидай на порожню частину контейнера, щоб додати в кінець.
- Перемога — всі ліхтарі ввімкнені. Скидання зберігає програму та повертає стан рівня до початкового.

## GitHub Pages

Гра працює статично з відносними URL, у тому числі в підпапці репозиторію. Публікуй levels разом із рештою файлів. Запис через адмінку потребує локального Node.js-сервера; GitHub Pages його не запускає. На Pages доступні редагування, тестування й експорт JSON, але не запис на сервер. Пряме відкриття index.html через file:// не підтримується через ES-модулі.

Three.js 0.180.0 лежить у vendor; ліцензія поряд. Інших мережевих залежностей немає. Музика синтезується Web Audio, не використовує сторонніх записів.

## Блоки для основ програмування

У нових рівнях і в налаштуваннях доступних команд редактора є:
- **if**: датчик або порівняння; кнопки **+ elif**, **+ else**. Виконується лише перша істинна гілка.
- **while**: перевіряє умову перед кожним повторенням. Скидання зупиняє програму; обмеження 1500 кроків захищає від нескінченного циклу.
- **AND / OR / NOT**: група умов виконується за правилом «усі» або «хоча б одна»; кожну умову можна заперечити. Для складніших поєднань використовуй вкладені if.
- Порівняння **=, ≠, <, ≤, >, ≥**: числа, висота, кількість ліхтарів, довжина списку, елемент за індексом або поточний елемент обходу.
- **Функція**: іменований набір команд. Без параметрів, return і рекурсії. Кнопка «Створити» додає визначення; блок «Функція» викликає його.
- **Список**: іменований ряд чисел через кому. Додати, змінити, видалити елемент або очистити список. Індекси починаються з 0.
- **Для кожного**: обхід початкової копії списку; значення доступне як «Поточний елемент». Додавання до списку під час обходу не подовжує поточний обхід.

У вкладеній області натисни «+ Команди…», щоб команди з палітри додавалися туди, або перетягуй їх. Натискання на порожнє місце основної програми повертає додавання до неї. Функції також враховуються в ліміті блоків. Під час запуску видно поточний вміст списків; новий запуск починає з початкових чисел.

Додано рівні «Розумна вулиця», «Одна дія — багато разів», «Маршрут зі списку». Старі рівні зберігають свій набір команд. Для власного рівня ввімкни потрібні команди в /admin/ і збережи.

Перевірки мови: `node --test --test-isolation=none tests/language.test.mjs tests/game.test.mjs`.

## Архітектура та карта проєкту для ШІ та розробників

Проєкт структуровано за принципом модульності та чіткого розділення відповідальності («один модуль — одна задача»):

### Структура модулів

| Файл / Модуль | Призначення та зона відповідальності |
|---|---|
| `logic-world.mjs` | **Світ і фізика гри**: правила переміщення, висоти, перевірка ліхтарів і хатинок, датчики (`sensorValue`, `conditionValue`), стан перемоги. |
| `logic-validate.mjs` | **Валідація**: перевірка коректності структури рівнів (`validateLevel`) та синтаксису блоків програми (`validateProgram`, підрахунок блоків). |
| `logic-run.mjs` | **Виконання програми**: компіляція дерева AST (`compile`), пам'ять/змінні/списки (`createMemory`), інтерпретатор (`executeProgram`). |
| `logic.mjs` | **Головний фасад логіки**: реекспортує всі функції з `logic-world`, `logic-validate`, `logic-run` для повної зворотної сумісності. |
| `program-icons.js` | **SVG-іконки блоків**: візуальні піктограми для команд і панелі інструментів. |
| `program-blocks.js` | **Конструктор елементів інтерфейсу блоків**: генерація DOM-форм для if, while, repeat, списків, редактор умов і значень. |
| `program-dnd.js` | **Перетягування блоків (Drag & Drop)**: обробка покажчика (pointer capture), привидні блоки (ghosts), зони скидання та кошик. |
| `program.js` | **Редактор програми**: координація редактора, синхронізація з localStorage, дерево програми, точки вставки. |
| `runner.js` | **Виконання та анімація**: покроковий запуск програми на карті, пауза, швидкість, керування кнопками «Пуск»/«Скидання», конфеті. |
| `scene.js` | **3D-сцена (Three.js)**: рендеринг ізометричного світу, кубів, персонажа (Ліхтарника), дерев, хатинок, ліхтарів, анімація руху й світла. |
| `home.js` | **Головне меню**: вибір категорій, карток рівнів, прогрес проходження та розблокування котів/досягнень. |
| `app.js` | **Головний контролер застосунку**: маршрутизація (хеші `#level/`, `#home`), перемикання тем, координація між модулями. |
| `blocks.css` | **Стилі візуальних блоків**: палітра команд, вкладені блоки, умови, випадаючі списки, фокус і підсвічування. |
| `game.css` | **Стилі гри**: розмітка 3D-полотна, верхньої панелі керування, заборона небажаного виділення тексту при драгу. |
| `admin/level-storage.js` | **Мережевий шар адмінки**: завантаження та збереження рівнів через API `/api/levels`, утиліти ID та слагов. |
| `admin/level-state.js` | **Керування станом редактора**: повноцінна історія дій (Undo та Redo), чернетка в `localStorage`, ініціалізація рівнів. |
| `admin/map-editor.js` | **2D-редактор карти**: рендеринг сітки 2D SVG, кольори висот, візуалізація дверей хатинок, перевірка меж. |
| `admin/map-paint.js` | **Малювання карти**: обробка подій миші на сітці, інструменти (висота, ліхтар, хатинка, дерево, старт, гумка). |
| `admin/map-resize.js` | **Зміна розмірів карти**: алгоритм розумного зсуву вмісту карти, перенесення старту, інтерактивна матриця вибору розміру. |
| `admin/admin.js` | **Головний координатор адмінки**: ініціалізація інтерфейсу редактора, прив'язка панелей, збереження та тестування. |
| `server.cjs` | **Локальний HTTP-сервер**: роздача статичних файлів (js/mjs/css/json) та REST API для збереження рівнів. |

### Швидка навігація для розширення функціоналу

- **Додати нову команду/блок**:
  1. `logic-run.mjs` — логіка виконання команди у компіляторі.
  2. `program-icons.js` — додайте SVG-іконку нової команди.
  3. `program-blocks.js` — додайте розмітку блоку та його параметри.
  4. `program.js` — додайте команду до палітри дозволених блоків.
  5. `blocks.css` — стилі для нового блоку.
- **Додати новий датчик або умову**:
  1. `logic-world.mjs` — функція `sensorValue()` або `conditionValue()`.
  2. `program-blocks.js` — опція у випадаючому списку умов/сенсорів.
- **Змінити правила валідації рівня**:
  1. `logic-validate.mjs` — перевірки у `validateLevel()`.
- **Змінити зовнішній вигляд або 3D-моделі**:
  1. `scene.js` — генерація геометрій Three.js для блоків, ліхтарів, будівель.
- **Змінити логіку редактора рівнів**:
  1. `admin/map-paint.js` — малювання інструментами на 2D-сітці.
  2. `admin/map-resize.js` — правила зміни розмірів поля.
  3. `admin/level-state.js` — стан та історія дій чернетки (Undo/Redo).
  4. `admin/level-storage.js` — робота з бекендом.
